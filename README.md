ДЗ 1.
Инструкция:
1. Склонировать репозиторий проекта для локального использования любым удобным способом
1. В терминале перейти в директорию с проектом
2. Выполнить команду
```
docker compose up -d
```
3. Дождаться сборки
4. Импортировать в Postman коллекцию из директории
```
postman/hl_homework1.postman_collection.json
```
5. Напротив названия коллекции нажать на знак троеточия ("..."), выбрать пункт "Run", нажать кнопку "Run hl_homework1..."
